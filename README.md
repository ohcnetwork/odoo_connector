# OHC Odoo Connector
Hospital Management System - Odoo Integration

## Care Connector Module

The Care Connector module integrates Odoo with the Open Healthcare Network (OHC) Care system.

### Features

- **Care Back Linking**: Click through from Odoo records directly to Care resources. [Learn more](care_connector/README.md)
- Synchronization of Partners, Products, Invoices, and Payments between Care and Odoo
- API endpoints for Care system integration

### Configuration

See the [Care Connector README](care_connector/README.md) for detailed configuration instructions.
